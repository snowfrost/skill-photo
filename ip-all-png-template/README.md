# IP All PNG Template

一个用于生成中文文章配图提示词的通用 Skill 模板。

它保留固定基础画风：**简笔画、白纸手绘、概念草图、文章正文配图**。

它扣掉的只有两件事：固定 IP 形象和固定配色。使用者只需要填写自己的 IP 角色公式和品牌配色，就可以把文章、知识点、教程内容转成一套带个人风格的配图 Prompt。

## 适合做什么

- 公众号文章正文配图
- 小红书知识卡片插图
- 教程文章概念图
- 视频封面元素草图
- 个人 IP 风格化 PNG 提示词
- 批量文章配图 shot list

## 核心思路

普通配图模板解决的是“这张图好不好看”。

IP 配图模板解决的是“别人能不能记住这是你”。

所以这个 Skill 不会内置某个固定角色，而是要求使用者先填写自己的 IP 形象和配色规则。后续所有图片 Prompt 都会围绕这套规则生成，保证风格稳定。

注意：基础画风不需要用户重新填，也不建议改。这个模板默认就是简笔画白纸手绘概念图。

## 固定基础画风

```text
基础画风：
16:9 横版中文文章配图，简笔画风格，纯白背景，大面积留白。
整体像白纸上的手绘概念草图，而不是海报、卡片或正式信息图。
画面以细黑色手绘线条为主，线条略微自然抖动，有手画感。
结构清晰、元素少，一张图只表达一个核心观点。
可以使用少量中文手写标注，通常 2-4 个短标签。
构图偏“知识解释图 / 产品草图 / 白板涂鸦”，用低技术感的隐喻物件表达概念，比如纸盒、抽屉、漏斗、天平、门、梯子、管道、线团、黑箱、旧机器等。
IP 角色只作为小引导者出现，默认占画面宽度 8%-12%，不要成为画面主体。
整体干净、克制、轻松，有一点荒诞的概念表达，但不要做成小红书密集卡片、PPT 信息图、商业海报、3D 渲染或复杂架构图。
```

也就是说：

```text
固定项：简笔画白纸手绘概念图
用户填写项：IP 形象 + 配色
```

## IP 形象填写公式

使用前先填写下面这组信息：

```text
年龄:
性别:
头发颜色:
头发长短/发型:
衣服颜色:
衣服款式:
衣服长短:
裙子/裤子颜色:
裙子/裤子款式:
裙子/裤子长短:
鞋子颜色:
鞋子款式:
鞋子长短/高度:
可选配饰:
可选陪伴物/宠物/道具:
角色气质:
```

一句话公式：

```text
年龄 + 性别 + 头发颜色长短 + 衣服颜色款式长短 + 裙子/裤子颜色款式长短 + 鞋颜色款式长短
```

## 配色填写公式

```text
主色:
辅助色:
强调色:
背景色:
禁用颜色:
整体风格关键词:
```

配色也要固定，不要每次生成都换一套风格。角色负责“是谁”，配色负责“像不像你”。

## 文件说明

- `SKILL.md`: Skill 主说明文件，定义使用流程、输出格式和 Prompt 模板。
- `references/ip-visual-template-json.md`: 可复用的结构化视觉 JSON 模板。
- `agents/openai.yaml`: Agent 展示名、简介和默认调用提示。

## 使用方式

把整个目录放到你的 Skills 目录中，例如：

```text
~/.codex/skills/ip-all-png-template
```

然后在对话中调用：

```text
[$ip-all-png-template] 根据这篇文章生成 3 张正文配图 Prompt
```

如果还没有填写 IP 信息，Skill 会先引导你填写角色公式和配色规则。

## 输出内容

默认输出：

- 3-6 个配图创意
- 每张图的结构类型
- IP 角色在图中做什么
- 可用道具和隐喻
- 中文手写标签建议
- 可直接复制使用的英文文生图 Prompt

## 注意事项

- 不要修改基础画风，默认就是简笔画白纸手绘概念图。
- 不要把 IP 形象写得太泛，否则生成结果会漂。
- 不要频繁换配色，否则用户很难形成视觉记忆。
- 每张图只表达一个核心观点。
- 默认保持角色小一点，让它作为“引导者”出现，而不是抢走主体。
- 如果要做海报、封面或小红书卡片，可以在需求里明确说明，Skill 会放宽版式密度。
