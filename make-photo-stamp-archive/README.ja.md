# Make Photo Stamp Archive

[简体中文](README.md) · [English](README.en.md) · **日本語**

Make Photo Stamp Archive は、1 枚または複数の写真を静かで抑制されたアーカイブ作品へ変換する Codex Skill です。元写真を忠実に保った写真パネルと、被写体に合わせて設計した小さな手押し印を置く温白色の紙パネルを、まっすぐな境界で直接つなぎます。

呼び出し名は `make-photo-stamp-archive` です。

## 主な機能

- 人物、顔、物、建築、文字、色の関係、場面の論理を含め、元写真を忠実に保持します。
- 標準は横長の左右直結レイアウトです。要望に応じて上下配置にも変更でき、主境界は常に明確で直線的に保ちます。
- 被写体に合わせて、円形、正方形の枠、横長、アーチ形、または独自シルエットの印を設計します。
- かすれたインク、摩耗したハーフトーン、圧力むら、欠けた輪郭、控えめな版ずれによって、実際に手で押したような質感を作ります。
- 印の形、枠、サイズ、位置、インク色、キャプション、紙の古さ、接合方向だけを限定して修正できます。
- 複数の写真には、写真ごとに独立した完成画像を生成します。

## ビジュアルシステム

- **写真パネル：**写実的に忠実さを保ち、標準ではキャンバスの約 55% を使用します。
- **紙パネル：**細かな繊維と軽いスキャン跡を持つ清潔な温白色の紙で、約 45% を使用します。
- **印のグループ：**小さくまとめて隅に配置し、紙パネルの約 30% に収めます。
- **余白：**紙パネルのおよそ 70% を静かな空白として残します。
- **キャプション：**小さく褪せたタイプライター文字を印の近くに置き、印には重ねません。
- **雰囲気：**抑制的、平面的、触覚的、アーカイブ的で、保存された記憶のような印象です。

最終結果は常に 1 枚の平面作品です。本のモックアップ、スクラップブック、ビフォー／アフターボード、縮小写真の貼り付け、装飾的なポスター展示にはしません。

## 動作要件

- Codex、または互換性のある Skill 実行環境。
- 元写真を確認するための画像読み取り機能。
- 完成画像の生成と修正に使う画像生成または編集機能。

この Skill パッケージには、API キー、外部フォント、スクリプト、追加ダウンロードが必要な実行素材は含まれていません。最終的な画質と元写真の保持精度は、実行環境で利用できる画像モデルに依存します。

## インストール

```bash
git clone https://github.com/Dlcccc71913/skill-make-photo-stamp-archive.git
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skill-make-photo-stamp-archive \
  "${CODEX_HOME:-$HOME/.codex}/skills/make-photo-stamp-archive"
```

Skill がすぐに表示されない場合は Codex を再起動してください。

## 使い方

```text
$make-photo-stamp-archive を使って、この写真をカスタム印付きの直結アーカイブ作品にしてください。
```

一部分だけを修正する場合：

```text
写真パネルは完全に変えず、印だけを 10% 小さくして右上へ移動してください。
```
