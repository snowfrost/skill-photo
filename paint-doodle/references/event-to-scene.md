# Event To Scene

Convert one event topic into 2 to 6 visible fragments on a single crude canvas.

## Fragment count

- Use 2 fragments for a simple before/after or cause/result event.
- Use 3 to 4 fragments for a short sequence.
- Use 5 to 6 fragments only when the event genuinely needs multiple beats to be legible.

Do not collapse everything into one crowded pile. Do not stretch it into a polished comic page.

## Fragment design

For each fragment, decide internally:

- the key action
- the few objects that must be visible
- the visible mistake opportunity, such as broken outline, bad fill, or warped perspective
- the exaggerated pose or reaction that makes the fragment readable without labels

Each fragment should show something the viewer can immediately see, not an abstract concept that only works as text.

## Layout guidance

- Prefer a loose collage on one plain white page instead of clean panels.
- Allow uneven spacing, floating objects, and bad alignment.
- Keep all fragments on one plain canvas unless the user explicitly asks for separated panels.
- Let the same character or object reappear in multiple spots across the page.
- Do not use arrows.
- Do not use visible sequence numbers such as `1.` or `2.`.
- Prefer very little text, not zero text. Use 1 to 3 tiny hand-written phrases total when they help the scene read faster.
- Let dramatic pointing, reaching, bending, hopping, surprise faces, and overacted body language carry the explanation.
- Leave generous blank space between scene fragments so the page feels like scattered doodles, not a dense storyboard.
- Make the composition looser than logical. A tiny vignette can float far away from the main cluster if it adds charm.

## Scene simplification

Prefer the smallest number of objects that still communicates the event.

Good:

- one rider, one bike, one puddle, one fall
- one person, one desk, one spilled cup, one laptop

Bad:

- full city block, crowd, weather system, complex interiors, decorative background details

## Forbidden scene drift

Do not turn the scene into:

- a clean storyboard
- a children’s picture book
- a polished meme template
- a cinematic moment with strong composition
- boxed comic panels unless the user asks for them
- an instruction sheet with arrows and numbered captions

Keep the fragments readable but amateur.
