# Paint Doodle 使用说明

`Paint Doodle` 是一个专门用来生成“潦草 MS Paint 风格事件解释图 / 成语解释图 / 吐槽重现图”的 Skill。

它追求的不是精致插画，而是这种效果：

- 白纸上散着几坨小场景
- 线条像鼠标手抖画出来的
- 颜色或灰色填充都不均匀
- 人物动作夸张
- 文字很少，但不是完全没有
- 看起来像“想说明白，但又画得很烂”

---

## 1. 文件结构

```text
SKILL.md
references/
  semantic-analysis.md
  event-to-scene.md
  object-degradation.md
  visual-style.md
  prompt-compiler.md
  visual-evaluation.md
  examples.md
README.MD
```

各文件作用：

- `SKILL.md`
  Skill 入口文件，定义触发条件、主流程、默认配色和硬规则。
- `references/semantic-analysis.md`
  先判断主题、角色、边界、色彩模式、文字预算。
- `references/event-to-scene.md`
  把一个事件拆成 2 到 6 个可见小场景，并规定构图松散度。
- `references/object-degradation.md`
  规定人物、物体、道具该怎么故意画歪、画糙、画坏。
- `references/visual-style.md`
  规定彩色模式、黑白模式、线条、填色、留白和整体潦草程度。
- `references/prompt-compiler.md`
  把分析结果拼成最终提示词。
- `references/visual-evaluation.md`
  生成前的自检清单。
- `references/examples.md`
  示例 prompt，只用于理解结构，不直接继承旧对象、旧布局、旧配色。

## 2. 适用场景

这个 Skill 适合：

- 成语解释图
- 事件示意图
- 吐槽式重现图
- 荒诞小故事解释图
- “用潦草画风把一件事讲明白”

例如：

- `拾金不昧`
- `曹冲称象`
- `哑巴吃黄连`
- `画一个人骑车掉进水坑的解释图`
- `给我一个潦草的 MS Paint 成语图`

---

## 3. 画风目标

### 页面结构

- 一张白底大纸
- 2 到 6 个散落的小场景
- 留白要多
- 不排成整齐漫画分镜
- 同一个人物可以在不同位置重复出现

### 线条和动作

- 黑色轮廓线为主
- 线条可以抖、断、重描、没收干净
- 比例可以歪
- 动作和表情要比现实更夸张
- 更像“随手乱画但想说明白”

### 文字

- 允许有字，但必须少
- 默认只保留 1 到 3 处很短的手写字
- 不要长段说明
- 不要箭头
- 不要序号

### 潦草感

当前版本的“潦草”包括：

- 反复改线
- 轮廓没闭合
- 填色越线
- 填色断断续续
- 一笔一笔乱刷
- 局部像半成品

## 4. 色彩模式

Skill 每次都会重新判断色彩模式，优先级是：

```text
custom_palette > monochrome > color
```

默认模式是：

```text
color
```

也就是用户没特别说时，默认出彩色。

### `color`

默认模式。特征：

- 使用 4 到 7 种刺眼的旧版画图软件纯色
- 可以错填、漏填、越线
- 不允许渐变
- 不允许专业配色感

典型颜色：

- 黑
- 红
- 蓝
- 绿
- 黄
- 棕
- 紫

### `monochrome`

只有用户明确要求黑白时才启用。

当前黑白模式不是“纯黑块”，而是：

- 白底
- 黑色轮廓
- 灰色铅笔乱刷填充
- 灰色可以不均匀、断断续续
- 不出现彩色
- 不出现精致数码灰度

更接近：

- 黑线 + 灰色乱刷的手绘说明图

### `custom_palette`

用户指定颜色时启用，例如：

- `只用红黑`
- `蓝色线条`
- `黄色背景`
- `黑白加一点红色`

这种模式下必须严格听用户指定颜色范围，不额外发明新颜色。

## 5. 生成流程

内部推荐流程如下：

1. 先判断主题是什么
2. 再判断配色模式
3. 把事件拆成 2 到 6 个可见小场景
4. 确定哪些动作和表情负责讲故事
5. 控制文字只留 1 到 3 处短字
6. 按潦草规则把对象画坏
7. 生成前做自检

可以把它理解成：

```text
先想清楚讲什么
再决定分彩色还是黑白
再把它拆成几坨散着的小画面
最后故意画得像没画好
```

---

## 6. 当前默认规则

当前 Skill 的重要默认值：

- 默认彩色，不默认黑白
- 黑白时使用“黑线 + 灰色乱刷”，不是纯黑块
- 不要箭头
- 不要序号
- 文字要少，但不是完全没有
- 更依赖夸张动作，不依赖解释文字
- 构图更松散，不排整齐
- 留白要够

## 8. 常见调整项

### 想更潦草

可以说：

- `线条再抖一点`
- `填色更乱一点`
- `像半成品一样`
- `更像小孩拿鼠标乱涂`

### 想少字

可以说：

- `文字再少一点`
- `只留两三个短字`

### 想保留一点文字

可以说：

- `不要完全没字`
- `保留两三处手写字`

### 想更松散

可以说：

- `构图更散一点`
- `留白更多一点`
- `不要排太整齐`

### 想更像黑白参考图

可以说：

- `黑白的时候按黑线+灰色乱刷来`

---

## 9. 默认避免的内容

当前 Skill 默认避免：

- 箭头
- 序号
- 整齐分镜
- 大段说明文字
- 过于精致的插画感
- 柔和高级配色
- 渐变
- 正规阴影
- 专业材质表现
