## Install
Copy the contents of this repository into your `~/.workbuddy/skills/` directory (or drag each folder in). WorkBuddy discovers any folder containing a `SKILL.md`.

## Source
Original upstream repos are credited in each skill's `SKILL.md`. This bundle (`skill-photo`) is a convenience collection for one-step install.
